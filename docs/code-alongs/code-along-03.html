Median & Mean with dplyr

Use dplyr grammar to find the frequency, mean, and median.

Add lots of summary variables using functions inside summarise().

  1. Use n() function to create a count variable (no variable in parentheses)
  2. Use mean() function on a variable
  3. Use median() function on a variable
gss_all |>  
  drop_na(agekdbrn) |> 
  summarise(
    freq = n(), 
    med = median(agekdbrn),
    avg = mean(agekdbrn)
    ) 
# A tibble: 1 × 3
   freq   med   avg
  <int> <dbl> <dbl>
1 28867    23  24.1

group_by() and summarize()

A common pipeline is group_by() and then summarize() to calculate summary statistics for each group:

Use group_by() to organize your data into groups based on one or more variables.
Use summarize() to compute statistics like total, mean, or median for each group.

  1. Start with the gss_all data frame:
  2. Remove any observations with missing data for our key variables
  3. Do the next steps separately for each group in the variable
  4. Creates a new data frame with one row for each combination of grouping variables
gss_all |>  
  drop_na(sex, agekdbrn) |> 
  group_by(sex) |> 
  summarise(avg = mean(agekdbrn)) 
# A tibble: 2 × 2
  sex          avg
  <dbl+lbl>  <dbl>
1 1 [male]    25.7
2 2 [female]  23.0

  group_by(as_factor(sex)) |>
